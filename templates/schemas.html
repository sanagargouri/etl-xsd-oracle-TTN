« Créer / Mettre à jour les tables » ne renomme jamais rien -- elle crée les tables manquantes en respectant le nom déjà configuré s'il y en a un, et ajoute automatiquement les colonnes manquantes si le XSD a évolué depuis la dernière fois (ALTER TABLE ADD COLUMN). « Renommer » exige que la table existe déjà (crée-la d'abord si besoin) et effectue un vrai renommage (ALTER TABLE RENAME) : les données et les liens avec les tables enfants sont conservés. Un nom déjà pris par une autre table entraîne un refus explicite plutôt qu'une écriture silencieuse dans la mauvaise table. Un fichier XSD identique ou très similaire à un schéma déjà connu est affiché avec un badge « Copie de... » plutôt que d'être masqué -- il reste visible même s'il n'apporte rien de nouveau.
